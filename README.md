# PivotPoint 🎯 - Linear Algebra Educational Web Application

**PivotPoint** is a modern, interactive, entirely client-side web application designed to support the learning and teaching of key practical topics in Linear Algebra, specifically focusing on pivoting, matrix inversion, determinant calculation, and solving systems of linear equations.

The software is tailored both for university students for independent, step-by-step practice, and for educators to instantly generate customized, printable exam papers (zárthelyi) along with their corresponding \LaTeX\ source codes.

👉 **[Click here to open the web application](https://pivotpointmark.github.io/PivotPoint/)**

---

## 🌟 Key Features

### 1. 🧮 Interactive Matrix Inversion
* Dynamic matrix dimension adjustments (from $2 \times 2$ up to $5 \times 5$).
* Step-by-step basis changes (pivoting) with clear visual feedback.
* Built-in divide-by-zero protection with intuitive error messaging.
* Row sorting feature to automatically align the identity matrix for a clean final look.

### 2. 📐 Determinant Calculation (Two Methods)
* **Expansion Method:** Visual representation of the classical Laplace expansion.
* **Pivoting Method:** Triangulation of the matrix (reducing to upper triangular form) and multiplying the main diagonal elements.
* Intelligent task generator equipped with pedagogical filters (zero control, determinant value boundaries, and integer-step pivoting checks).

### 3. ⛓️ Solving Systems of Linear Equations
* Input systems manually or populate them using the random generator.
* Exact mathematical handling and explanation of the three possible outcomes:
  * **Unique solution** (a single coordinate vector).
  * **Inconsistent system** (no solution).
  * **Infinite solutions** (parametric representation with custom free variables).
* Automatic row-swapping to ensure correct variable indexing.

### 4. 🎓 Teacher's Task Generator (Exam Maker)
* **"Full Generation (Teacher's)"** algorithm: Creates a special upper triangular matrix that guarantees students will be able to select a pivot element of $\pm 1$ at every single step, preventing complex fractions early in the exam.
* Interactive manipulation: Perform manual row/column swaps and row operations (adding a scalar multiple of one row to another) on the generated matrix.

### 5. 📄 Client-Side PDF Generation & Printing
* Integrated `@media print` CSS stylesheets to hide web-only interface elements (buttons, navigation headers).
* **MathJax Async Sync:** A JavaScript Promise-based chain waits until the MathJax rendering engine has fully rendered all mathematical formulas into SVG format before triggering `window.print()`, preventing blank or half-rendered formulas in the exported PDF.

## 🛠️ Tech Stack

The primary design goal was **complete portability and zero server-side dependencies**.

* **HTML5:** For the semantic structure of the web interface.
* **CSS3:** For a responsive, modern layout equipped with printing directives (`@media print`).
* **JavaScript (ES6+):** Powers the core mathematical engine, DOM manipulation, and asynchronous communication.
* **MathJax v3 (TypeScript/JS):** Renders high-quality, sharp, responsive vector equations and \LaTeX\ symbols.
* **CounterAPI:** A free external microservice called asynchronously via `fetch` to globally track the number of exam sheets generated by educators, removing the need to manage a backend database.
